# intus 홈페이지 개편 초안

IR draft와 GEO 운영안을 반영한 로컬 정적 홈페이지입니다.

## 실행

로컬 관리자까지 쓰려면 아래 명령으로 서버를 실행합니다.

```powershell
cd C:\intus-homepage
npm start
```

- 홈페이지: http://127.0.0.1:5177/
- 임시 관리자: http://127.0.0.1:5177/admin.html

`index.html`을 직접 열어도 기본 홈페이지는 보이지만, 파일 업로드 관리 기능은 로컬 서버에서만 저장됩니다.

## 반영 방향

- 포지셔닝: GOYO 단품이 아니라 피부 진동 신호 기반 차세대 음성·생체 센싱 AI 플랫폼
- 사업영역: H2H, H2M(Physical AI HMI), Medical 3개 탭 구조
- H2H: 현재 GOYO 산업 통신 홈페이지의 핵심 내용 유지
- H2M: 소음 환경에서 Physical AI가 필요로 하는 인간 의도 입력 레이어로 설명
- Medical: 경동맥 피부 진동 센싱 연구 트랙으로 표현하고, 의료 효능 주장은 제한
- GEO: H2H/H2M/Medical 질문 의도별 콘텐츠 허브 섹션 추가

## 임시 관리자 기능

관리자 페이지에서 변경할 수 있는 항목:

- 표지 이미지
- 홍보영상 MP4
- 4개 음성 데모 파일 및 한영 라벨
- CES·글로벌 고객 사진 갤러리

사진 갤러리는 `공개 동의·사용 권리 확인`이 체크된 항목만 `site-config.js`에 저장되어 홈페이지에 노출됩니다.

## 주요 파일

- `index.html`: 메인 홈페이지
- `styles.css`: 메인 스타일
- `script.js`: 언어 전환, 사업영역 탭, 설정 반영
- `site-config.js`: 관리자에서 바뀌는 표지/오디오/갤러리 설정
- `admin.html`: 임시 관리자 페이지
- `admin-server.js`: 외부 의존성 없는 로컬 관리자 서버
- `assets/`: 기본 이미지, 영상, 오디오, PDF

- CES 고객 사진의 초상권, 상표권, 파트너십 오인 가능성
